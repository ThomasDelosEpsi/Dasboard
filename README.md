# Dashboard Personnel de Priorités

Petite application web (mono-page) pour organiser ses journées de travail : gestion de tâches avec priorités, journal quotidien, minuteur de focus (type Pomodoro) et génération automatique d'un mail de compte-rendu.

## Stack

- HTML / CSS / JavaScript vanilla (aucun framework, aucune dépendance)

## Usage

Ouvrir `index.html` dans un navigateur. Les données sont conservées localement côté client.
